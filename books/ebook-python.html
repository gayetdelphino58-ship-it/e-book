Chapitre 1

Pourquoi apprendre Python ?

Python est aujourd'hui le langage de programmation le plus populaire au monde. Créé en 1991 par Guido van Rossum, il est devenu en 30 ans le couteau suisse des développeurs : simple à apprendre, puissant à utiliser, et présent dans tous les domaines.

Python est utilisé pour...

  • 🤖 Intelligence Artificielle & Machine Learning : TensorFlow, PyTorch, scikit-learn.
  • 🌐 Développement Web : Django, Flask — Instagram et Pinterest l'utilisent.
  • 📊 Analyse de données : Pandas, NumPy, Matplotlib.
  • 🔒 Cybersécurité : Tests de pénétration, scripts d'audit.
  • 🤖 Automatisation : Scripts pour automatiser les tâches répétitives.
  • 🎮 Jeux vidéo : Pygame pour créer des jeux simples.
💡 À Retenir

Python est le langage numéro 1 pour l'IA, la data science et l'automatisation. En 2025, un développeur Python junior gagne en moyenne 800 000 à 2 000 000 FCFA/mois en freelance international.

Chapitre 2

Installation et Premier Programme

Installer Python

  • Rendez-vous sur python.org
  • Téléchargez la dernière version (Python 3.12+)
  • Lors de l'installation, cochez "Add Python to PATH"
  • Installez aussi VS Code (éditeur gratuit de Microsoft)

Votre premier programme

La tradition en programmation est d'écrire un programme qui affiche "Bonjour le monde !". Voici comment faire en Python :

# Mon premier programme Python print("Bonjour le monde !") print("Je commence Python aujourd'hui !")

Résultat dans le terminal :

Bonjour le monde ! Je commence Python aujourd'hui !
💡 À Retenir

La fonction print() est la plus utilisée en Python. Elle affiche du texte dans la console. Les textes (chaînes de caractères) sont entourés de guillemets simples ou doubles.

Chapitre 3

Variables, Types et Opérateurs

Une variable est une boîte qui stocke une valeur. En Python, vous créez une variable simplement en lui donnant un nom et une valeur.

# Créer des variables nom = "Alice" age = 25 prix = 9.99 est_actif = True print(nom) # Affiche : Alice print(age) # Affiche : 25 print(prix) # Affiche : 9.99

Les types de données principaux

  • str : Chaîne de texte — "Bonjour", 'Python'
  • int : Nombre entier — 42, -10, 0
  • float : Nombre décimal — 3.14, 9.99
  • bool : Vrai ou Faux — True, False
  • list : Liste de valeurs — [1, 2, 3, "pomme"]

Opérateurs mathématiques

a = 10 b = 3 print(a + b) # Addition : 13 print(a - b) # Soustraction : 7 print(a * b) # Multiplication : 30 print(a / b) # Division : 3.333... print(a ** b) # Puissance : 1000 print(a % b) # Modulo (reste) : 1
Chapitre 4

Conditions et Boucles

Les conditions (if/elif/else)

Les conditions permettent d'exécuter du code différent selon une situation.

age = 18 if age >= 18: print("Vous êtes majeur !") elif age >= 13: print("Vous êtes adolescent.") else: print("Vous êtes enfant.")

La boucle for

# Afficher les nombres de 1 à 5 for i in range(1, 6): print(i) # Parcourir une liste fruits = ["mangue", "papaye", "ananas"] for fruit in fruits: print("J'aime la", fruit)

La boucle while

compteur = 0 while compteur < 5: print("Compteur :", compteur) compteur += 1 # Équivaut à compteur = compteur + 1
💡 À Retenir

En Python, l'indentation (espaces en début de ligne) est obligatoire. Elle remplace les accolades {} d'autres langages. Utilisez toujours 4 espaces ou une tabulation.

Chapitre 5

Fonctions et Modules

Une fonction est un bloc de code réutilisable. Au lieu de répéter le même code 10 fois, vous créez une fonction et l'appelez quand vous en avez besoin.

# Créer une fonction def saluer(nom): print(f"Bonjour, {nom} ! Bienvenue.") # Appeler la fonction saluer("Jean") # Affiche : Bonjour, Jean ! Bienvenue. saluer("Marie") # Affiche : Bonjour, Marie ! Bienvenue. # Fonction avec valeur de retour def calculer_tva(prix): return prix * 1.18 total = calculer_tva(1000) print(f"Prix TTC : {total} FCFA") # 1180 FCFA

Les modules Python

Python possède des milliers de modules (bibliothèques) prêts à l'emploi :

import math import random import datetime print(math.sqrt(16)) # Racine carrée : 4.0 print(random.randint(1,6)) # Dé aléatoire : 1-6 print(datetime.date.today()) # Date du jour

Chapitre 7

Introduction à la Programmation Orientée Objet

La Programmation Orientée Objet (POO) permet d'organiser le code en "objets" qui combinent données et comportements.

# Créer une classe class Voiture: def __init__(self, marque, couleur): self.marque = marque self.couleur = couleur self.vitesse = 0 def accelerer(self, valeur): self.vitesse += valeur print(f"{self.marque} accélère à {self.vitesse} km/h") # Créer des objets ma_voiture = Voiture("Toyota", "rouge") ma_voiture.accelerer(50) # Toyota accélère à 50 km/h ma_voiture.accelerer(30) # Toyota accélère à 80 km/h
💡 À Retenir

La POO est essentielle pour les grands projets. Elle permet de créer du code réutilisable, maintenable et organisé. Tous les frameworks Python modernes (Django, FastAPI) utilisent la POO.
