Chapitre 1

Introduction aux Réseaux Informatiques

Un réseau informatique est un ensemble d'appareils (ordinateurs, téléphones, serveurs, imprimantes) interconnectés pour partager des ressources et communiquer. Internet est le plus grand réseau du monde — un "réseau de réseaux".

Types de réseaux

  • LAN (Local Area Network) : Réseau local — votre box internet chez vous ou dans un bureau.
  • WAN (Wide Area Network) : Réseau étendu — Internet est un WAN mondial.
  • MAN (Metropolitan Area Network) : Réseau métropolitain — réseau d'une ville.
  • WLAN (Wireless LAN) : Réseau local sans fil — le WiFi.
  • VPN (Virtual Private Network) : Réseau privé virtuel — tunnel sécurisé sur Internet.

Les topologies réseau

Topologie en étoile (la plus courante) : [PC1]─┐ [PC2]─┤──[SWITCH/ROUTEUR]──Internet [PC3]─┘ Topologie en bus : [PC1]──[PC2]──[PC3]──[PC4] (câble unique partagé) Topologie en anneau : [PC1]──[PC2]──[PC3]──[PC4]──[PC1]
💡 À Retenir

La topologie en étoile est la plus utilisée aujourd'hui car une panne d'un équipement n'affecte pas les autres. C'est ce que vous avez chez vous : votre box WiFi est le centre de l'étoile.

Chapitre 2

Le Modèle OSI et TCP/IP

Le modèle OSI (Open Systems Interconnection) est une référence qui divise la communication réseau en 7 couches. Chaque couche a un rôle précis et communique avec les couches adjacentes.

CoucheNomRôleExemple
7ApplicationInterface utilisateurHTTP, FTP, DNS, SMTP
6PrésentationFormatage, chiffrementSSL/TLS, JPEG, MP4
5SessionGestion des sessionsNetBIOS, RPC
4TransportTransmission fiableTCP, UDP
3RéseauAdressage et routageIP, ICMP (ping)
2LiaisonTransmission localeEthernet, WiFi, MAC
1PhysiqueTransmission bitsCâbles, fibres, ondes

TCP/IP — Le protocole d'Internet

TCP/IP est le protocole universel d'Internet. TCP assure que les données arrivent complètes et dans l'ordre. IP adresse et route les paquets de données à travers les réseaux.

Chapitre 3

Équipements Réseau

  • 🔌 Hub : Équipement basique qui envoie les données à TOUS les appareils connectés. Obsolète, peu efficace.
  • 🔀 Switch (Commutateur) : Plus intelligent que le hub — envoie les données uniquement à l'appareil destinataire. Base du réseau local.
  • 📡 Routeur : Connecte différents réseaux entre eux (votre réseau local ↔ Internet). Votre "box" est un routeur.
  • 🛡️ Firewall : Filtre le trafic réseau pour bloquer les menaces. Premier rempart de sécurité.
  • 📶 Point d'accès WiFi (AP) : Crée un réseau sans fil dans une zone.
  • ⚡ Modem : Convertit le signal Internet (fibre, ADSL) en signal réseau utilisable.
💡 À Retenir

Votre box FAI (Moov Fibre, MTN...) est en réalité un appareil multifonction : modem + routeur + switch + point d'accès WiFi. Un appareil, 4 fonctions !

Chapitre 4

Adressage IP et Sous-réseaux

Chaque appareil sur un réseau possède une adresse IP unique, comme une adresse postale. Il existe deux versions : IPv4 (ex : 192.168.1.1) et IPv6 (ex : 2001:db8::1).

Classes d'adresses IPv4

Adresses PRIVÉES (réseau local) : Classe A : 10.0.0.0 – 10.255.255.255 Classe B : 172.16.0.0 – 172.31.255.255 Classe C : 192.168.0.0 – 192.168.255.255 Adresses PUBLIQUES : attribuées par votre FAI Votre box a une IP publique (ex: 197.234.x.x) Vos appareils ont des IP privées (192.168.1.x)

Le masque de sous-réseau

Réseau typique à la maison : IP de la box : 192.168.1.1 IP de votre PC : 192.168.1.100 IP de votre téléphone: 192.168.1.101 Masque : 255.255.255.0 (ou /24) Commande pour voir son IP (Windows) : ipconfig Commande pour voir son IP (Linux/Mac): ip addr ou ifconfig

Commandes réseau utiles

ping 8.8.8.8 → Tester la connexion à Google ping 192.168.1.1 → Tester la connexion au routeur ipconfig /all → Afficher toutes les infos réseau (Windows) tracert google.com → Tracer le chemin vers un serveur nslookup google.com → Résolution DNS
Chapitre 5

WiFi et Réseaux Sans Fil

Le WiFi (Wireless Fidelity) utilise des ondes radio pour connecter les appareils sans câble. Les standards WiFi évoluent régulièrement pour plus de vitesse et de portée.

StandardNomVitesse maxFréquence
802.11nWiFi 4600 Mbps2.4/5 GHz
802.11acWiFi 53.5 Gbps5 GHz
802.11axWiFi 69.6 Gbps2.4/5/6 GHz

Sécuriser son WiFi

  • 🔒 Utiliser WPA3 (ou minimum WPA2) — jamais WEP (trop vulnérable)
  • 🔑 Mot de passe fort : 12+ caractères, majuscules, chiffres, symboles
  • 📶 Changer le nom du réseau (SSID) par défaut
  • 🚫 Désactiver le WPS (vulnérabilité connue)
  • 🔄 Mettre à jour le firmware du routeur régulièrement
Chapitre 6

Sécurité des Réseaux

La cybersécurité est l'un des domaines informatiques les plus demandés et les mieux payés. Les entreprises cherchent désespérément des experts pour protéger leurs systèmes.

Les principales menaces réseau

  • 🦠 Malwares : Virus, trojans, ransomwares qui infectent les systèmes.
  • 🎣 Phishing : Faux emails/sites pour voler mots de passe et données.
  • 💥 DDoS : Attaque par saturation — inonder un serveur de requêtes jusqu'à la panne.
  • 🕵️ Man in the Middle : Intercepter la communication entre deux parties.
  • 🔓 SQL Injection : Exploiter les failles de bases de données web.

Les défenses essentielles

  • 🛡️ Firewall (pare-feu) bien configuré
  • 🔒 Chiffrement des données (HTTPS, VPN)
  • 🔄 Mises à jour régulières de tous les systèmes
  • 👤 Principe du moindre privilège (chaque utilisateur n'a accès qu'à ce dont il a besoin)
  • 💾 Sauvegardes régulières (règle 3-2-1)
Chapitre 7

Réseaux d'Entreprise et VPN

Les entreprises ont des besoins réseau plus complexes que les particuliers. La sécurité, la haute disponibilité et la scalabilité sont prioritaires.

Le VPN (Virtual Private Network)

Un VPN crée un tunnel chiffré entre votre appareil et un serveur distant. Utilisations principales :

  • 🔒 Sécuriser les connexions des employés en télétravail
  • 🌍 Contourner les restrictions géographiques
  • 🕵️ Préserver la vie privée (masquer son IP)
  • 🏢 Connecter les bureaux distants d'une entreprise
# Exemple de configuration OpenVPN sur Linux sudo apt install openvpn sudo openvpn --config votre-config.ovpn # Vérifier votre nouvelle IP curl ifconfig.me
Chapitre 8

Carrières et Certifications Réseau

Les métiers des réseaux informatiques sont parmi les mieux rémunérés du secteur IT, avec une forte demande en Afrique et à l'international.

Les certifications les plus reconnues

  • 🥇 CCNA (Cisco Certified Network Associate) : La certification réseau la plus connue. Salaire moyen : 1 200 – 3 000 €/mois en Europe.
  • 🥈 CompTIA Network+ : Certification généraliste reconnue mondialement.
  • 🥉 CompTIA Security+ : Spécialisation cybersécurité, très demandée.
  • ⭐ CCNP (Cisco Certified Network Professional) : Niveau avancé après CCNA.

Plan de carrière recommandé

  • Mois 1-3 : Bases réseaux (ce livre + ressources YouTube)
  • Mois 4-6 : Préparation CompTIA Network+ (200-300 €)
  • Mois 7-12 : Préparation CCNA (300 €)
  • Après CCNA : Emploi en entreprise ou freelance international

Un technicien réseau certifié CCNA au Bénin peut décrocher des contrats freelance sur Upwork et Fiverr avec des clients américains et européens, facturant 30-80$/heure.
