Chapitre 1

Découvrir l'Interface Excel

Microsoft Excel est le tableur le plus utilisé dans le monde professionnel. Maîtriser Excel, c'est avoir un avantage considérable dans n'importe quel emploi ou business. Voici les éléments clés de l'interface :

  • Barre de formules : Affiche le contenu de la cellule sélectionnée. C'est ici que vous saisissez vos formules.
  • Cellules : Chaque case identifiée par une lettre (colonne) et un chiffre (ligne). Ex : A1, B2, C10.
  • Feuilles : Les onglets en bas. Un fichier Excel peut contenir plusieurs feuilles.
  • Ruban : La barre d'outils en haut avec tous les boutons de mise en forme et outils.
💡 Raccourcis indispensables

Ctrl+S = Sauvegarder | Ctrl+C = Copier | Ctrl+V = Coller | Ctrl+Z = Annuler | Ctrl+F = Rechercher | Ctrl+Flèche = Naviguer rapidement

Chapitre 3

Les Formules Essentielles

Formules de base

=SOMME(A1:A10) → Additionne les cellules A1 à A10 =MOYENNE(B1:B10) → Calcule la moyenne =MAX(C1:C10) → Valeur maximale =MIN(C1:C10) → Valeur minimale =NB(D1:D10) → Compte les cellules non vides =NBVAL(D1:D10) → Compte les cellules avec texte ou nombres

La formule SI (très importante)

=SI(A1>=10; "Reçu"; "Échoué") → Si A1 est supérieur ou égal à 10, afficher "Reçu", sinon "Échoué" =SI(B2>1000000; "VIP"; SI(B2>500000; "Standard"; "Basic")) → SI imbriqués pour plusieurs conditions

RECHERCHEV — La formule star

=RECHERCHEV(valeur_cherchée; tableau; numéro_colonne; 0) Exemple : Trouver le prix d'un produit à partir de son code : =RECHERCHEV(A2; $F$2:$H$100; 2; 0)
💡 À Retenir

Toute formule Excel commence par le signe = (égal). Sans ce signe, Excel considère le contenu comme du texte simple, pas une formule.

Chapitre 4

Graphiques et Visualisations

Un graphique communique en quelques secondes ce qu'un tableau de chiffres met des minutes à expliquer. Excel propose une dizaine de types de graphiques.

Créer un graphique en 3 clics

  • 1. Sélectionnez vos données (en-têtes inclus)
  • 2. Onglet "Insertion" → "Graphiques recommandés"
  • 3. Choisissez le type → OK

Quel graphique pour quelle situation ?

  • 📊 Histogramme/Barres : Comparer des catégories (ventes par produit)
  • 📈 Courbes : Évolution dans le temps (ventes mensuelles)
  • 🥧 Secteurs (camembert) : Parts d'un tout (répartition du budget)
  • 🔵 Nuage de points : Corrélation entre deux variables
Chapitre 5

Tableaux Croisés Dynamiques

Le tableau croisé dynamique (TCD) est l'outil le plus puissant d'Excel. Il permet d'analyser des milliers de lignes de données en quelques secondes, sans une seule formule.

Créer un TCD en 4 étapes

  • 1. Cliquez dans votre tableau de données
  • 2. Insertion → Tableau croisé dynamique → OK
  • 3. Faites glisser les champs dans les zones (Lignes, Colonnes, Valeurs, Filtres)
  • 4. Excel calcule tout automatiquement !
💡 À Retenir

Avec un TCD, vous pouvez en 30 secondes répondre à : "Quels sont mes 5 meilleurs clients ?", "Quel produit se vend le mieux en saison des pluies ?", "Quelle est ma marge par catégorie ?"

Chapitre 7

Introduction aux Macros

Les macros permettent d'automatiser des tâches répétitives. Plutôt que de refaire les mêmes manipulations chaque semaine, vous enregistrez une macro et vous l'exécutez en un clic.

Enregistrer une macro simple

  • 1. Onglet "Développeur" → "Enregistrer une macro"
  • 2. Donnez-lui un nom et un raccourci clavier (Ex : Ctrl+Maj+F)
  • 3. Effectuez les actions à automatiser
  • 4. Cliquez "Arrêter l'enregistrement"
  • 5. Appuyez sur votre raccourci pour rejouer la macro !
Chapitre 8

Analyse de Données Avancée

La mise en forme conditionnelle

Colorez automatiquement vos cellules selon leur valeur. Ex : rouge si ventes < objectif, vert si ventes > objectif. Sélectionnez les cellules → Accueil → Mise en forme conditionnelle.

Les filtres et tris avancés

Filtrez vos données en un clic : Données → Filtrer. Ensuite, cliquez sur la flèche de chaque colonne pour filtrer par valeur, couleur ou condition.

La fonction SIERREUR

=SIERREUR(RECHERCHEV(A2;Tableau;2;0); "Non trouvé") → Évite l'affichage des erreurs #N/A dans vos tableaux
💡 À Retenir

Un fichier Excel bien construit peut vous faire économiser des heures de travail chaque semaine. Investissez 2-3 heures pour créer vos modèles une fois, puis bénéficiez-en à vie.
